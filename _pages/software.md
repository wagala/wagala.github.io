# jBBMF
## Joint Bayesian Boolean Matrix Factorization

**Status:** Active development

**Paper:** Coming soon

**Repository:** [wagala/jBBMF](https://github.com/wagala/jBBMF)

An extension of BBMF for jointly analyzing paired binary datasets through shared latent signatures and dependent loading matrices, enabling Bayesian data integration and uncertainty quantification.
