## Overview

This project develops **Bayesian Boolean Matrix Factorization (BBooMF)** methods for discovering
latent structure in **binary** genomic data, with a focus on Multiple Myeloma (MM) copy‑number
alterations (CNAs) collected at diagnosis and relapse.

MM CNA data encode the presence or absence of chromosomal events such as deletions and gains.
Representing these profiles as Boolean matrices allows us to model **presence–absence patterns**
directly, without forcing continuous approximations or arbitrary thresholds.

## 1. Bayesian Boolean Matrix Factorization (BBooMF)

BBooMF assumes that an observed Boolean matrix \(X\) is generated from an underlying latent Boolean
structure. Two latent components are introduced:

- a **loading matrix** \(W\), indicating which features belong to each factor, and  
- a **latent pattern matrix** \(H\), describing which factors are active for each sample.

Using Boolean algebra, the reconstruction of \(X\) is obtained via logical AND (conjunction) and OR
(disjunction) operations between \(W\) and \(H\). The observed data are treated as a noisy realization
of this ideal Boolean reconstruction.

Advantages:

- **Interpretability** – a 1 is predicted only when a factor is active in a sample and contributes that
  feature; multiple factors combine through logical OR.  
- **Discrete modelling** – the method respects the binary nature of the data, avoiding the need to
  threshold continuous factorizations.  

To learn \(W\) and \(H\), the model uses:

- **Beta–Bernoulli priors** on the entries of \(W\) and \(H\), which control sparsity and factor usage.  
- A **spike‑and‑slab prior** on the columns of \(H\), enabling the model to switch entire latent
  factors on or off and thereby regulate complexity.

These hierarchical priors yield an interpretable, probabilistic framework that discovers concise and
structured Boolean patterns.

## 2. Joint Bayesian Boolean Matrix Factorization (JBBooMF)

The **Joint BBooMF** extension simultaneously factorizes two related Boolean datasets,
\(X^{(1)}\) and \(X^{(2)}\):

- \(X^{(1)}\) has loading matrix \(W^{(1)}\)  
- \(X^{(2)}\) has loading matrix \(W^{(2)}\)  
- both share a common latent pattern matrix \(H\)

Each dataset is generated by the same Boolean mechanism: a combination of its loading matrix and the
shared patterns in \(H\), followed by a simple noise model.

### Application to MM Diagnosis and Relapse

For MM CNA profiles:

- \(X^{(1)}\): CNAs at **diagnosis**  
- \(X^{(2)}\): CNAs at **relapse**  

The shared \(H\) captures **latent CNA patterns** that underlie both stages, while \(W^{(1)}\) and
\(W^{(2)}\) reflect how strongly each pattern is expressed at each time point.

Because the spike‑and‑slab prior on \(H\) determines which factors are globally active, the model:

- highlights patterns that **persist** from diagnosis to relapse, and  
- identifies patterns that **change** or **emerge** at relapse.

This joint factorization provides an interpretable tool for studying chromosomal evolution in MM and
for generating hypotheses about mechanisms of treatment resistance and disease progression.
